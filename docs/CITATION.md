# Citation

Please cite the *prioritizr R* package when using it in publications. To
cite the package, please cite the following article.

> Hanson JO, Schuster R, Strimas‐Mackey M, Morrell N, Edwards BPM,
> Arcese P, Bennett JR, and Possingham HP (2025) Systematic conservation
> prioritization with the prioritizr R package. *Conservation Biology*,
> **39**: e14376.

Additionally, if your work uses the multi-objective optimization
functionality, please cite the following article as well.

> Neubert S, Richardson AJ, Metcalfe K, McGowan J, Possingham HP, Dabalà
> A, Buenafe KCV, Chapman M, Jung M, Visconti P, Everett JD, Dunn DC,
> Mohammadi A, Zhao J, and Hanson JO (2026) Advancing multi‐objective
> optimization in spatial planning. *Journal of Applied Ecology*,
> **63**: e70617.
